# 4HRS

Bauhaus-inspired fashion e-commerce foundation.

## Phase 1

Phase 1 establishes the production foundation, design-token layer, reusable UI primitives, global layout, accessibility baseline, and provider-neutral architecture boundaries.

### Explicitly deferred

- Products and catalog business logic
- Product CRUD/importing
- Database business models
- Customer authentication
- Cart/checkout/orders
- Payments
- Shipping
- Fulfillment provider APIs
- Admin business logic
- Inventory logic

## Commands

```bash
npm install
npm run dev
npm run lint
npm run typecheck
npm run build
```
